# @pterodocs/docusaurus

Reads a [pterodocs](https://github.com/onyx-ac/pterodoc) site model out of Docusaurus,
through Docusaurus's own site loader — so resolved sidebars, versions, locales,
permalinks and draft flags all come from the same code that builds your site.

You probably want the [`pterodocs`](https://www.npmjs.com/package/pterodocs) package
instead.
